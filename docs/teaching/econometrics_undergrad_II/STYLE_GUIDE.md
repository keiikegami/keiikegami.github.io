## 0. コースの位置づけと読者像

- 計量経済学I（https://keiikegami.github.io/econometrics_undergrad.html）の続編。
  受講者の事前知識は計量Iの範囲のみと想定する：OLS（単回帰・重回帰）、ロバスト標準誤差、t検定・信頼区間、
  ダミー変数、固定効果、DiD、操作変数法（2SLS、Wald推定量）、RDD、潜在アウトカムによる因果推論の基礎、
  「モデル＝条件付き分布の束」「識別・推定・推論の3ステップ」という枠組み、Rの基本操作。
- **計量Iで扱っていないもの**（本講義で初出のたびに丁寧に導入・復習すること）：
  最尤法、GMM、離散選択モデル、ベイズ推定、行列計算の込み入った操作、動的計画法、機械学習。
- 受講者は実証IO・quantitative marketingの初学者。公開講座として**企業のデータ分析担当者**も多数受講する。
  企業内データ（POS、ECログ、広告配信ログ、CRM、アプリ行動ログ）を想定した例を積極的に使うこと。

## 2. 実行環境に関する最重要注意

- **この執筆環境にはRもQuartoも無い。レンダーやRコードの実行は不可能**。レンダーは後でユーザーのMac上で行う。
- したがってRコードは「一発で動く」ことを最優先に、保守的に書くこと：
  - 使用パッケージは §6 のwhitelistのみ。マイナーな関数・引数を使わない。
  - 関数シグネチャ（引数名・戻り値の構造）に確信が持てない場合は、base Rで自作する方を選ぶ。
  - chunk間の変数依存を丁寧に管理する（上から順に実行して必ず通るように）。
  - 数値計算のロジック（縮小写像、動的計画法、尤度、GMM）は、**まずPython/numpy（この環境で実行可能）で
    プロトタイプして収束・数値を確認してから**Rに書き起こすこと。強く推奨。
- `install.packages()`, `download.file()`, `read.csv()`（外部ファイル）, `url()`, `Sys.setlocale()` を
  qmd内に書くことは**禁止**。

## 7. 記法統一（コース全体で共通）

**需要・離散選択（第2〜6回）**
- 消費者 $i$、財 $j$（$j = 0$ はoutside option）、市場 $t$。財の数は $J$。
- 効用：$u_{ijt} = \delta_{jt} + \varepsilon_{ijt}$、$\delta_{jt} = x_{jt}'\beta - \alpha p_{jt} + \xi_{jt}$。
  $\varepsilon_{ijt}$ はType I極値分布（Gumbel）。$\alpha > 0$（価格係数はマイナスを明示した書き方）。
- logitシェア：$s_{jt} = \exp(\delta_{jt}) / (1 + \sum_{k=1}^{J} \exp(\delta_{kt}))$。
- Berry反転：$\ln s_{jt} - \ln s_{0t} = \delta_{jt}$。
- 自己価格弾力性：$\eta_{jj} = -\alpha p_j (1 - s_j)$、交差弾力性：$\eta_{jk} = \alpha p_k s_k$。
- random coefficient：$\beta_i = \beta + \Sigma^{1/2} \nu_i$、$\nu_i \sim N(0, I)$。個人部分は $\mu_{ijt}$。
- nested logit：ネスト $g$、ネスト内相関 $\rho$、within-nest share $\bar{s}_{j|g}$。

**因果推論（第7,8,11回）**
- 処置 $D_i \in \{0,1\}$、潜在アウトカム $Y_i(1), Y_i(0)$、観測 $Y_i = D_i Y_i(1) + (1-D_i) Y_i(0)$。
- ATE $\tau = E[Y(1) - Y(0)]$、CATE $\tau(x) = E[Y(1) - Y(0) \mid X = x]$、傾向スコア $e(x)$。
- パネル：個体固定効果 $\mu_i$、時間固定効果 $\lambda_t$（※ $\alpha$ は価格係数に予約済みなので使わない）。

**階層モデル（第9,10回）**
- 個人（店舗）パラメータ $\theta_i$、超パラメータ：$\theta_i \sim N(\bar\theta, \tau^2)$。
- BG/NBD等は当該文献の標準記法（$\lambda, r, \alpha, a, b$）をそのまま使い、
  「この回の $\alpha$ はガンマ分布のパラメータで、需要推定の価格係数とは無関係」と明示的に断る。

**動学（第13〜15回）**
- 状態 $x_t$、行動 $a_t$、**割引因子は $\beta$**（この3回では効用パラメータは $\theta$ と書き、
  「需要推定の回では $\beta$ は選好パラメータだったが、動学の慣習に合わせて割引因子に使う」と初出時に断る）。
- 価値関数 $V(x)$、選択固有価値関数 $v(x, a)$、Emax・logsum公式、条件付き選択確率 $P(a \mid x)$。

## 8. 講義ノートの構成テンプレート

1. **冒頭callout**（重要）：「この講義で押さえたいこと」を3〜5点。
2. **前回とのつながり・今回のゴール**：シラバスの「前後とのつながり」を膨らませ、コース全体の地図の中の現在地を示す。
3. **本文**：概念 → モデル（条件付き分布の束として明示）→ **Rシミュレーション**（DGPをコードで書く）→
   識別 → 推定（真値を回収できるか必ず確認）→ 推論（SE・CI・検定、可能ならモンテカルロで標本分布を可視化）。
   - 計量Iの哲学「モデルを書けばシミュレーションできる。シミュレーションできれば推定量の性質を実験で確かめられる」を全回で貫く。
   - 図は積極的に。1ノートあたりR chunk 8〜15個、図6個以上を目安。
4. **まとめcallout**（重要）：箇条書き4〜6点。
5. **宿題**：軽い予習・復習タスク（計量I風。「ChatGPTに○○と聞いてみよう」「このコードの△△を変えて遊んでみよう」等）
   ＋「coding課題は `assignment{N}.qmd` を参照」の一文。
6. **次回予告**：1段落。
7. **参考文献**：シラバスのReading全件＋追加文献。本文で触れた論文は全てここに載せる。

## 9. callout規約（Quarto記法）

| 用途 | 記法 | タイトル例 |
|---|---|---|
| 核心メッセージ・冒頭/まとめ | `::: {.callout-important}` | 「この講義で押さえたいこと」「ここが核心」 |
| 企業データでの具体例 | `::: {.callout-note}` | 「ビジネスの現場で：コンビニの缶コーヒー棚」 |
| 実証研究の紹介 | `::: {.callout-tip}` | 「実証研究コーナー：Blake, Nosko and Tadelis (2015)」 |
| 落とし穴・よくある誤用 | `::: {.callout-warning}` | 「この分析、どこがまずい？」 |
| 導出細部・発展的補足 | `::: {.callout-note collapse="true"}` | 「導出：logitの選択確率」 |

- タイトルは `## 見出し` をcallout内の1行目に置く記法で付ける。
- 「ビジネスの現場で」は1ノートに2つ以上、「実証研究コーナー」は1ノートに3つ以上入れること。
- 実証研究コーナーの中身：研究の問い／データ／識別戦略・モデル／主要な発見（**具体的な数値**を1つは入れる）／
  なぜこの講義のトピックと繋がるのか、を5〜10文で。

## 10. coding課題（assignment{N}.qmd）の仕様

その回のコアとなる統計技術（識別・推定・推論）について、**必ず2部構成**にする：

- **Part 1：シミュレーション設計**（自分でDGPを書く）
  - モデル（条件付き分布の束）を数式で与え、指定パラメータでデータ生成コードを書かせる。
  - データの可視化と記述統計まで。
  - 檔当回のノートのDGPと構造は同じでも、設定（財の数、パラメータ値、文脈）は変えること。
- **Part 2：推定・推論**（Part 1のデータを使う）
  - 推定量の実装（可能な限り自作。optim等）、真値との比較。
  - 推論：SEの計算、信頼区間、検定、またはモンテカルロ反復による標本分布・被覆率の確認のいずれかを必ず含む。
  - 最後に1問、「経営・政策への含意を3行で書け」という解釈問題を置く。
- 各設問に配点目安（合計100点）、必要に応じて`#| eval: false`のコード骨格（穴埋め）を与える。
- 難易度調整：手を動かせば2〜4時間で終わる分量。ヒントcalloutを惜しまない。

**solution{N}.qmd**：全設問の完全な実行可能コード＋「なぜこう書くか」「どこで間違えやすいか」の解説。
配点基準（何ができていれば部分点か）も簡潔に付す。
