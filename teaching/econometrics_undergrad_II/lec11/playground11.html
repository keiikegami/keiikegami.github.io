実験1：「解約しそうな人に施策」は正しいか

「解約しそうな顧客にこそ引き留めクーポンを配るべきだ」。誰もが思いつくこの方針が失敗しうることを、Ascarza (2018) は実際のRCTで示した。鍵は、解約リスクの高さと、施策への感応度（CATE）

\[ \tau(x) = E[Y(1) - Y(0) \mid X = x] \]

がまったく別の量だという点にある。ここでは通信キャリアのクーポンRCT（10,000人、50%にランダム配布、アウトカムは翌月の継続）をシミュレートする。risk_slope が「リスクが高い人ほど効果が下がる」構造の強さを決めるノブだ。予算内（上位25%）に配るとして、(a) リスクスコア順、(b) uplift（T-learnerの \(\hat\tau(x)\)）順、(c) ランダム、の3通りを比べる。true_total_effect は配った人たちの真の効果の合計（＝本当に防げる解約数）、est_incremental_stays はRCTログの群間差から推定した増分継続者数である。

リスク上位を狙う (a) は、ランダムに配る (c) にすら負ける。高リスク層は「もう決めている」lost causesと「触ると逆効果」のsleeping dogsが集まる場所だからである。

ノートやってみよう
  • risk_slope <- -0.4（CATEとリスクが正相関する世界）にすると、(a)と(b)の差はどうなるか。予想してから実行しよう。このときリスクスコアはupliftの良い代理変数になる。
  • budget_frac を0.05と0.5に変えて、(b)と(c)の差（ターゲティングの賢さの価値）が予算のどの水準で最も大きく出るか確かめよう。
  • risk_slope <- 0（効果が誰でもほぼ同じ世界）でも、(b)が(c)に少し勝ったり負けたりする。これは本物の差か、推定ノイズか。set.seed を変えて何度か回すとどう確かめられるか。

実験2：Qini曲線 — 膨らみの源泉は効果の異質性

ターゲティングの良し悪しを1枚で見る道具がQini曲線である。横軸は「上位何%に配ったか」、縦軸は「累積の増分継続者数」。並べ方が賢いほど曲線は上に膨らみ、ランダムに配ればほぼ直線（対角線）になる。膨らみを生むのは効果の異質性そのものだ。異質性の強さ hetero をいじって、uplift順・リスクスコア順・ランダムの3本の形がどう変わるかを見よう。

ノートやってみよう
  • hetero <- 0 にして、3本の線がほぼ1本の直線に重なることを確かめよう。効果が誰でも同じなら、賢く並べても意味がない。ターゲティングの価値は異質性の強さで決まる。
  • hetero <- 2 にすると、uplift順の膨らみと、リスクスコア順の「谷」（途中でマイナスに沈む区間）はどれだけ極端になるか。
  • 配布割合1.0（右端）では、どの並べ方でも3本の線が同じ点に戻る。なぜか。

実験3：IPWで施策ルールをオフライン評価する

新しい配分ルールを思いつくたびにA/Bテストをやり直すのはコストが高い。質の良いRCTログが1本あれば、任意のルール \(\pi(x)\) の政策価値をIPW（逆確率重み付け）で推定できる。

\[ \hat{V}(\pi) = \frac{1}{n} \sum_{i=1}^{n} \frac{\mathrm{1}\{D_i = \pi(X_i)\} \, Y_i}{P(D_i \mid X_i)} \]

ログの中で「たまたまルールと同じ割り当てを受けた人」だけを取り出し、割り当て確率（ここでは0.5）の逆数で重み付けする、という操作である。ここでは「推定uplift \(\hat\tau(x)\) が閾値以上の人にだけ配る」ルールを、全員配布・誰にも配らない、と比較する。value は各ルールの下での平均継続率（の推定値）だ。閾値を動かして、政策価値が最大になる場所を手で探してみよう。これが講義で触れたpolicy learningの入り口である。

「閾値ルール」は全員配布より配布割合が小さいのに、政策価値は同等以上になるはずだ。sleeping dogs（効果がマイナスの層）を外せるからである。

ノートやってみよう
  • threshold を-0.05、0、0.03、0.08と動かして、value が最大になる閾値を手で探そう。理屈の上では0付近が最適になるはずだが、実際の表ではどうか。
  • クーポン1枚のコストが継続率換算で0.02だとしよう。セルの最後に res$value - 0.02 * res$frac_treated を追加して、コスト込みの順位がどう変わるか見てみよう。最適な閾値も0より上に動くはずだ。
  • 最適な閾値を「同じデータで探して、同じデータで評価する」と、そのルールの価値は過大評価されがちである。なぜか。これがpolicy learningでsample splittingが必要になる理由につながる。
